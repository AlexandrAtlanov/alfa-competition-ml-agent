# Задача

Определи постановку задачи по описанию и структуре данных.

# Что вернуть (текстом, коротко)

1. Тип задачи: regression / classification (или иное).
2. Целевую колонку (target).
3. Колонку-идентификатор (id), если есть.
4. Метрику и направление оптимизации (меньше/больше — лучше).
5. 2–3 особенности данных, важные для выбора модели
   (пропуски, категориальные признаки, дисбаланс классов, выбросы).

# Ограничения

- Не предлагай код на этом шаге.
- Если метрика не указана явно — выведи её из типа задачи.
