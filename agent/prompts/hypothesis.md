# Задача

Предложи одну следующую гипотезу/эксперимент для улучшения модели.

# Правила

- Гипотеза атомарная: одно изменение за раз, чтобы эффект можно было измерить.
- Укажи: что меняем, зачем и как проверим (метрика на валидации).
- Учитывай, что уже пробовали, если это дано в контексте.
- Не повторяй уже проверенные гипотезы.
- Не предлагай EDA; данные уже подготовлены.
- Ответ — 3–5 предложений, без кода.

# Приоритет направлений

1. Обработка пропусков и кодирование категориальных признаков.
2. Новые признаки из имеющихся (отношения, агрегаты, дата-части).
3. Смена/настройка модели (GBDT → ансамбль, гиперпараметры).
4. Схема валидации и борьба с утечками.
