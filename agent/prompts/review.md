# Задача

Разбери результат выполнения сгенерированного кода: успех или баг.

# Что вернуть (JSON, коротко)

- `status` — `ok` / `bug` / `timeout` / `no_metric` / `error`.
- `reason` — причина в одном-двух предложениях (по stderr / стектрейсу).
- `next_action` — что исправить или попробовать дальше (или null).
- `leak_suspected` — есть ли подозрение на утечку данных / подгонку под метрику.
- `metric_found` — найдена ли метрика в выводе.

# Правила

- Не предлагай полный код; только диагноз и направление правки.
- Если запуск упал по таймауту — `status = "timeout"`.
- Не пересказывай весь лог, выбери суть.
