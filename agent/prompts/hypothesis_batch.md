# Задача

Предложи РАЗНЫХ кандидатов-гипотез для улучшения текущей лучшей модели.
Модель и CV фиксированы каркасом: LightGBM, 5-fold, метрику считает каркас.
Каждый кандидат — ОДНО атомарное изменение относительно текущей лучшей спеки.
Сколько кандидатов нужно и какие ключи гиперпараметров разрешены — сказано
в сообщении пользователя.

# Что можно менять (поле delta)

- "model_family": "lgbm" | "ridge" | "extratrees" — другое семейство модели.
  Меняй, только если есть содержательная причина (почти линейная зависимость,
  маленькая выборка, иной характер ошибок), и по одному семейству за раз.
- "lgbm_params": {...} — только ключи, перечисленные в сообщении пользователя.
  Имеют смысл только при "model_family": "lgbm".
- "class_weight": null | "balanced"  (только классификация).
- "target_transform": null | "log1p"  (только регрессия, таргет > -1).
- "postprocess": null | "class_weight_opt"  (только классификация: подбор
  весов под Macro F1).
- Новые признаки: delta = {}, а в "feature_idea" — конкретное описание, какие
  признаки построить из каких колонок (имена колонок — точно как в списке).
  Код напишет отдельный шаг.

# Правила

- Не повторяй уже проверенные гипотезы из истории; учитывай, что не сработало.
- Признаки должны вычисляться построчно или по train+test без таргета.
- expected_gain / cost: low | med | high (cost — время обучения).
- change_type: feature | encoding | preprocessing | model | validation | ensemble |
  other.
