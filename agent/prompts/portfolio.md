# Задача

Выбери из портфеля семейства моделей, которые имеет смысл обучить на этих
данных. Это отбор веток, а не подбор гиперпараметров: каркас дальше сам
оценит каждую ветку на кросс-валидации и будет их улучшать.

# Что учитывать

- Размер выборки: на десятках тысяч строк бустинги дороже и не всегда
  выигрывают; на очень широких данных линейные модели и kNN чувствительны к
  масштабу, но быстры.
- Тип задачи и метрика: для Macro F1 важны веса классов и подбор порогов;
  для RMSE — обработка хвостов и выбросов.
- Природа зависимости: если она близка к линейной, Ridge/LogReg даст
  сильную и дешёвую базу.
- Разнообразие: лучше выбрать разные по природе семейства (бустинг + деревья
  + линейная), чем пять похожих бустингов.

# Формат ответа

JSON по схеме: `families` — список имён из портфеля (не больше указанного
количества), `reasoning` — 2–4 предложения, почему именно эти.
